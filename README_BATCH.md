# 🚀 Rutube Downloader - Batch файлы для запуска

## 📁 Созданные файлы:

### 1. **`run_app.bat`** - Основной запуск
- Запускает приложение
- Показывает логи в отдельном окне
- Автоматически переходит в нужную папку

### 2. **`run_app_debug.bat`** - Запуск с отладкой
- Запускает приложение в режиме отладки
- Проверяет зависимости
- Показывает подробные логи

### 3. **`install_deps.bat`** - Установка зависимостей
- Устанавливает все необходимые Python пакеты
- Обновляет pip
- Проверяет установленные пакеты

## 🎯 Как использовать:

### **Первый запуск:**
1. **Дважды кликни** на `install_deps.bat`
2. Дождись завершения установки
3. **Дважды кликни** на `run_app.bat`

### **Обычный запуск:**
- **Дважды кликни** на `run_app.bat`

### **Если есть проблемы:**
- **Дважды кликни** на `run_app_debug.bat`

## ✅ Преимущества batch файлов:

- 🚀 **Быстрый запуск** - двойной клик
- 📊 **Логи видны** - все сообщения в отдельном окне
- 🔧 **Автоматическая настройка** - правильная папка
- 📱 **Удобно** - не нужно открывать терминал

## 🎮 Теперь можешь:

1. **Запускать приложение** двойным кликом
2. **Видеть все логи** в отдельном окне
3. **Копировать текст** из логов
4. **Легко отлаживать** проблемы

**Попробуй запустить `run_app.bat`!** 🚀✨
