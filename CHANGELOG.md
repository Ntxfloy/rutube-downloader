# История изменений

## Невыпущенное (ветка `fix/ui-clipboard-progress`)

### Исправленные баги

**Интерфейс**
- Ctrl+V не работал: бинды отсутствовали, а при русской раскладке Tk присылает
  keysym `Cyrillic_em`. Теперь Ctrl+V/C/X/A обрабатываются по keysym и по keycode,
  добавлены Shift+Insert и Command-бинды для macOS.
- Вставка больше не стирает всё поле, учитывает выделение, чистит переводы
  строк и не крадёт фокус (был `focus_force`).
- Кнопки «Остановить» и «Очистить очередь» вообще не отображались: вместо них
  дважды паковался их контейнер.
- Секции «Настройки» и «Прогресс» прыгали в конец окна при каждом анализе.
- Падение `AttributeError`, когда анализ ссылки возвращал ошибку (`content_info = None`).
- Статус-бар главного окна никогда не обновлялся — теперь показывает состояние.
- Убраны нечитаемые стили `inverse-*`, лишние модальные окна и заглушка
  `https://github.com/your-repo` в справке.

**Прогресс загрузки**
- Процент не показывался и бар часто висел на нуле: прогресс вытаскивался
  из текста статуса (`message.split("Прогресс:")`), а hook требовал `total_bytes`,
  которого у HLS-потоков Rutube просто нет.
- Теперь процент считается по цепочке `total_bytes` → `total_bytes_estimate` →
  фрагменты → `_percent_str`, а при полной неизвестности бар уходит в
  indeterminate вместо вечных 0%.
- Добавлены цифры процента, скорость, ETA, размер и общий прогресс очереди.
- Tk больше не трогается из рабочих потоков — всё идёт через `after()`.

**Ядро**
- Невалидный селектор формата `best[height<=720p]` (и `best[height<=worst]`).
- Кнопка «Остановить» не прерывала текущую загрузку yt-dlp.
- Рабочий поток спал, удерживая блокировку очереди.
- `os.statvfs` падал на Windows → `shutil.disk_usage`.
- `UnboundLocalError` в обработчике ошибок загрузки.
- Настройки и история терялись при запуске из другого каталога (относительный
  `data/`) → теперь профиль пользователя с автомиграцией и атомарной записью.
- Геометрия окна сохранялась на каждое событие `<Configure>` → debounce.

**Парсер**
- Ссылки серий собирались с литеральными фигурными скобками и были нерабочими.
- Количество серий угадывалось евристикой «любое число от 10 до 1000».
- Основной путь теперь — yt-dlp (`extract_flat`), HTML остался фолбэком.

**История**
- «Повторить скачивание» не работало (брался виджет вкладки вместо объекта фрейма).
- Удаление записи удаляло не ту запись (индекс вместо id).
- Поиск ломал порядок строк (detach/reattach) и использовал устаревший `trace("w")`.
- История и скачивание использовали разные менеджеры → записи не появлялись.
- Статус больше не ставится `completed` в момент добавления в очередь.

### Добавлено
- Общий прогресс очереди, скорость и ETA.
- Кнопка «Открыть папку», пункт меню и пункт «Вставить и анализировать».
- Настройки: количество одновременных загрузок, путь к ffmpeg, отключение всплывашек.
- Горячие клавиши: Enter — анализ, F5 — обновить историю, Ctrl+Q — выход.
- Автотесты (`tests/`) и CI на GitHub Actions (Python 3.11 и 3.12, GUI под xvfb).
