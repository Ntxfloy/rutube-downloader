# Rutube Downloader

Профессиональное приложение для скачивания видео и плейлистов с Rutube с современным интерфейсом и расширенной функциональностью.

## Возможности

- 🎬 **Автоматическое определение типа контента** - приложение само понимает, что вы хотите скачать: видео или плейлист
- 📺 **Скачивание плейлистов** - поддержка сериалов с выбором диапазона серий
- 🎯 **Гибкие настройки качества** - выбор качества видео (best, 720p, 480p, 360p, worst)
- 📁 **Выбор папки назначения** - настраиваемая папка для скачиваний (по умолчанию E:\anime)
- 📊 **История скачиваний** - полная история всех загрузок с возможностью повтора
- 🎨 **Современный интерфейс** - темная тема, минималистичный дизайн
- ⚡ **Многопоточность** - скачивание в фоновом режиме без блокировки интерфейса
- 🚀 **Оптимизированная производительность** - кеширование плейлистов и умная многопоточность

## Установка

### Требования

- Python 3.8 или выше
- Windows 10/11 (тестировалось на Windows 10)

### Пошаговая установка

1. **Клонируйте или скачайте проект**
   ```bash
   git clone <repository-url>
   cd Rutub_downloader
   ```

2. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение**
   ```bash
   python main.py
   ```

## Использование

### Основные функции

1. **Скачивание видео**
   - Вставьте ссылку на видео в поле ввода
   - Нажмите "Анализировать"
   - Выберите качество и папку назначения
   - Нажмите "Скачать"

2. **Скачивание плейлиста**
   - Вставьте ссылку на плейлист
   - Нажмите "Анализировать"
   - Укажите диапазон серий для скачивания
   - Выберите качество и папку
   - Нажмите "Скачать"

3. **История скачиваний**
   - Перейдите на вкладку "История"
   - Просматривайте все скачивания
   - Используйте поиск для быстрого нахождения
   - Двойной клик для повтора скачивания
   - Правый клик для дополнительных действий

### Настройки

- **Путь для скачивания** - измените папку по умолчанию
- **Качество видео** - установите предпочтительное качество
- **Дополнительные опции** - настройте сохранение превью и субтитров

## Технические детали

### Используемые библиотеки

- **yt-dlp** - мощная библиотека для скачивания видео
- **ttkbootstrap** - современные стили для tkinter
- **requests** - HTTP-запросы для парсинга
- **BeautifulSoup** - парсинг HTML-страниц

### Архитектура

Приложение построено по модульному принципу:
- **GUI модуль** - отвечает за пользовательский интерфейс
- **Core модуль** - содержит основную бизнес-логику
- **Utils модуль** - вспомогательные функции и утилиты

## Устранение неполадок

### Частые проблемы

1. **Ошибка импорта модулей**
   - Убедитесь, что все зависимости установлены: `pip install -r requirements.txt`

2. **Ошибка при скачивании**
   - Проверьте интернет-соединение
   - Убедитесь, что ссылка корректна и ведет на Rutube
   - Проверьте доступность видео (не заблокировано ли)

3. **Медленное скачивание**
   - Скорость зависит от вашего интернет-соединения
   - Попробуйте выбрать меньшее качество видео

### Логи и отладка

При возникновении ошибок проверьте:
- Консоль Python для детальных сообщений об ошибках
- Файлы в папке `data/` для логов приложения

## Создание исполняемого файла
