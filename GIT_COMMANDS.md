# 🚀 Быстрая загрузка на GitHub

## 📋 Что нужно сделать:

1. **Установить Git**: https://git-scm.com/download/win
2. **Создать приватный репозиторий** на GitHub
3. **Выполнить команды ниже**

## 🔧 Команды (копируйте и вставляйте):

```bash
# 1. Инициализация
git init

# 2. Добавить все файлы
git add .

# 3. Первый коммит
git commit -m "Initial commit: Rutube Downloader v1.0 - Полнофункциональное приложение для скачивания с Rutube"

# 4. Добавить удаленный репозиторий (ЗАМЕНИТЕ YOUR_USERNAME на ваш логин)
git remote add origin https://github.com/YOUR_USERNAME/rutube-downloader.git

# 5. Переименовать ветку
git branch -M main

# 6. Отправить на GitHub
git push -u origin main
```

## ⚠️ Важно:

- **ЗАМЕНИТЕ** `YOUR_USERNAME` на ваш логин GitHub
- **Название репозитория**: `rutube-downloader` (или любое другое)
- **Приватность**: ✅ Private
- **README**: ❌ Не создавать (у нас уже есть)

## 🔄 Для обновлений:

```bash
git add .
git commit -m "Описание изменений"
git push
```
