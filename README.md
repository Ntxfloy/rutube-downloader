# Rutube Downloader

Десктопное приложение на Python для скачивания видео и плейлистов с Rutube.
Интерфейс — Tkinter + ttkbootstrap, загрузка — yt-dlp.

## Возможности

- Одиночные видео, плейлисты и каналы, выбор диапазона серий.
- Выбор качества: `best`, `1080p`, `720p`, `480p`, `360p`, `240p`, `worst`.
- Прогресс с процентами, скоростью, ETA и общим прогрессом очереди.
- Параллельные загрузки, остановка и очистка очереди.
- История загрузок с поиском, повтором и статистикой.
- Настройки и история хранятся в профиле пользователя (`%APPDATA%/RutubeDownloader`,
  `~/.config/RutubeDownloader`, `~/Library/Application Support/RutubeDownloader`).

## Установка

```bash
pip install -r requirements.txt
python main.py
```

Для слияния видео и аудио нужен **ffmpeg** в `PATH` или в папке `ffmpeg/` рядом
с приложением. Путь можно указать вручную в «Файл → Настройки».
Без ffmpeg загрузка работает, но в один готовый файл без слияния потоков.

## Как пользоваться

1. Вставьте ссылку (Ctrl+V работает и в русской раскладке, есть контекстное меню).
2. «Анализировать» или Enter.
3. Выберите качество, диапазон серий и папку.
4. «Скачать» — прогресс виден в секции «Прогресс скачивания».

Горячие клавиши: `Ctrl+V` / `Shift+Insert` — вставка, `Ctrl+A` — выделить всё,
`Enter` — анализ, `F5` — обновить историю, `Ctrl+Q` — выход.

## Структура

```
core/downloader.py   — очередь загрузок, yt-dlp, расчёт прогресса
core/parser.py       — разбор ссылок и плейлистов
core/utils.py        — конфиг, история, валидация, форматирование
gui/main_window.py   — главное окно, меню, настройки
gui/download_frame.py— вкладка скачивания и прогресс
gui/history_frame.py — вкладка истории
tests/               — автотесты
```

## Тесты

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```

GUI-тесты требуют дисплея; на сервере запускайте их как `xvfb-run -a python -m pytest -q`
(именно так их гоняет CI). Без дисплея они автоматически пропускаются.
