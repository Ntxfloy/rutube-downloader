# Rutube Downloader

Приложение для скачивания видео и плейлистов с [Rutube](https://rutube.ru) с графическим интерфейсом.

## Возможности

- 📥 Скачивание одиночных видео и плейлистов
- 🎬 Выбор качества (best, 720p, 480p, 360p)
- 📋 Диапазон серий для плейлистов
- 📂 Динамический путь загрузки (папка Downloads/RutubeDownloads)
- 🕓 История скачиваний с поиском
- 🔧 ffmpeg опциональный — работает и без него

## Быстрый старт

### Готовый EXE (рекомендуется)

Скачайте `RutubeDownloader.exe` из [Releases](../../releases) и запустите. Никаких зависимостей устанавливать не нужно.

### Запуск из исходников

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите приложение:
   ```bash
   python main.py
   ```

## Установка ffmpeg (опционально)

ffmpeg нужен только для добавления метаданных к скачанным файлам.  
Без него приложение работает полностью — видео скачиваются корректно.

Скачать ffmpeg: https://ffmpeg.org/download.html  
Достаточно добавить папку с `ffmpeg.exe` в системный PATH,  
либо положить `ffmpeg/ffmpeg.exe` в папку рядом с приложением.

## Поддерживаемый контент

- Одиночные видео: `https://rutube.ru/video/...`
- Плейлисты и сериалы: `https://rutube.ru/plst/...`

## Системные требования

- Windows 10/11 (для EXE-версии)
- Python 3.9+ (для запуска из исходников)
