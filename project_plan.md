# План проекта: Rutube Downloader

## Обзор проекта
Профессиональное приложение для скачивания видео и плейлистов с Rutube с современным интерфейсом и функциональностью.

## Архитектура и технологии
- **Язык**: Python 3.8+
- **GUI**: tkinter (встроенный, легкий)
- **Скачивание**: yt-dlp (лучшая библиотека для скачивания)
- **Парсинг**: requests + BeautifulSoup
- **Хранение данных**: JSON файлы
- **Стилизация**: ttkbootstrap (темная тема)

## Структура проекта
```
Rutub_downloader/
├── main.py              # Главный файл приложения
├── gui/                 # Модули интерфейса
│   ├── __init__.py
│   ├── main_window.py   # Главное окно
│   ├── download_frame.py # Фрейм скачивания
│   └── history_frame.py # Фрейм истории
├── core/                # Основная логика
│   ├── __init__.py
│   ├── downloader.py    # Логика скачивания
│   ├── parser.py        # Парсинг Rutube
│   └── utils.py         # Утилиты
├── data/                # Данные приложения
│   ├── config.json      # Настройки
│   ├── history.json     # История скачиваний
│   └── downloads/       # Папка для скачиваний
├── requirements.txt      # Зависимости
└── README.md            # Документация
```
